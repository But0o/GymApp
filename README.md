# Gym

Registro de entrenamientos para el celular que funciona sin internet (PWA).

- Rutinas editables con series y repeticiones objetivo
- Entrenamiento con el peso de la última vez precargado y cronómetro de descanso
- Historial, récords y gráfico de progreso por ejercicio
- Copia de seguridad exportable en JSON

Los datos quedan guardados en el dispositivo. HTML, CSS y JS puro, sin dependencias.

**Instalar en iPhone:** abrir el link en Safari → Compartir → *Agregar a inicio*.
